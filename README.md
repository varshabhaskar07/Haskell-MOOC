# Haskell MOOC – My Course Progress and Solutions

This repository contains my solutions and notes from the [Haskell MOOC](https://haskell.mooc.fi/) – a free, open online course on Haskell programming. The course is designed by the University of Helsinki and is ideal for learning functional programming from scratch.

## 🧠 About the Course

Haskell MOOC introduces the core concepts of functional programming using Haskell. It covers:

- Functional programming basics
- Pure functions and immutability
- Higher-order functions
- Recursion and pattern matching
- Algebraic data types
- Type inference and type classes
- Monads and IO handling

## 🚀 Getting Started

To run any of the exercises locally, make sure you have:

* [GHC (Glasgow Haskell Compiler)](https://www.haskell.org/ghc/)
* [Stack](https://docs.haskellstack.org/en/stable/README/) or [GHCup](https://www.haskell.org/ghcup/) for managing environments

Example:

```bash
ghci filename.hs
```
